# Task Tracker Application

Dự án quản lý danh sách công việc (To-Do List) đơn giản, giao diện hiện đại, viết bằng HTML, CSS, và Vanilla JavaScript.

## Tính năng chính
- Thêm công việc mới nhanh chóng.
- Đánh dấu hoàn thành / chưa hoàn thành.
- Xóa từng công việc hoặc xóa toàn bộ công việc đã hoàn thành.
- Bộ lọc: Tất cả, Đang làm, Đã xong.
- Tự động lưu dữ liệu vào LocalStorage trên trình duyệt.

## Cách chạy dự án
Chỉ cần mở file `index.html` trên bất kỳ trình duyệt web nào (Chrome, Firefox, Edge, Safari) hoặc chạy live server.
